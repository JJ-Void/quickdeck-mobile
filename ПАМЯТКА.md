# QuickDeck для Android. Что нажимать

Программа на телефоне не собирается сама из архива — её собирает GitHub.
Ты заливаешь код один раз, дальше нажимаешь тег и получаешь готовый `.apk` по ссылке.

---

## Шаг 1. Залить код

Открой командную строку в папке `quickdeck-mobile-main` и введи:

```
git init
git add .
git commit -m "QuickDeck mobile 1.1.0"
git branch -M main
git remote add origin https://github.com/JJ-Void/quickdeck-mobile.git
git push -u origin main
```

Репозиторий создаётся на github.com кнопкой **New repository**, имя `quickdeck-mobile`.

Сразу после `push` начнётся сборка — вкладка **Actions**. Через 5–8 минут внизу
страницы сборки появится **QuickDeck-apk**. Это уже рабочий файл, можно качать и ставить.

## Шаг 2. Выпустить версию

```
git tag v1.1.0
git push origin v1.1.0
```

Теперь APK лежит в **Releases** — по прямой ссылке, её и раздаёшь.

## Шаг 3. Поставить на телефон

Скачал `.apk` → открыл → Android спросит «разрешить установку из этого источника» → разрешить.
Если Play Protect ругается на неизвестного разработчика — «Всё равно установить».

После установки:

1. Открыть QuickDeck.
2. Включить **Пузырь поверх приложений** — телефон попросит разрешение
   «Поверх других приложений», дать.
3. Пузырь появится у правого края. Долгим нажатием перетащи туда, где удобно
   большому пальцу — он запомнит место и прилипнет к ближайшему краю.

---

## Как этим пользоваться

Четыре жеста, больше запоминать нечего:

- **Тап по пузырю** — открылся список того раздела, где ты был в прошлый раз.
  Сверху четыре вкладки, между разделами переключаешься тапом.
- **Потянул пузырь в сторону** — под пальцем колесо разделов. Ведёшь вверх-вниз —
  выбираешь. Отпустил — открылся список.
- **Потянул дальше** (примерно на треть экрана) — у раздела появился плюс.
  Отпустил — сразу форма новой записи, без захода в список.
- **Вернул палец к пузырю и отпустил** — ничего не произошло, это отмена.
- **Долгое нажатие** — пузырь оторвался, тащи куда хочешь.

Закрыть панель можно тремя способами: тап по пузырю, тап мимо панели, крестик.
Убрать пузырь совсем — кнопка **Убрать пузырь** в уведомлении QuickDeck.

### Что можно сделать не открывая приложение

- Посмотреть карточку объекта или договора — сроки, суммы, стороны, просрочку.
- **Сменить статус одним тапом** — плашки прямо в карточке, ничего сохранять не надо.
- **Подвинуть готовность** кнопками −/+ по 10 %.
- Найти запись — кнопка с лупой, поиск идёт по объектам, договорам и сторонам.

Всё, где надо печатать, открывается отдельным листом с обычной клавиатурой.
Заказчика для объекта, объект и исполнителей для договора не надо вписывать руками —
они выбираются из того, что уже есть в реестре.

Удалить запись можно в форме: кнопка **Удалить запись**, потом подтверждение
вторым нажатием.

## Связь с таблицей

Теперь она работает **в обе стороны**: что поменял в телефоне — видно в таблице,
что поменял в таблице — приезжает в телефон.

### Разово: настроить таблицу

1. Создать таблицу на Google Диске.
2. Меню **Расширения → Apps Script**.
3. Стереть всё, вставить код из `SHEETS.md` (лежит рядом), сохранить.
4. **Развернуть → Новое развёртывание → Веб-приложение**:
   запуск — от моего имени, доступ — **все, у кого есть ссылка**.
5. Скопировать ссылку вида `https://script.google.com/macros/s/.../exec`.
6. В приложении вставить её в поле на главном экране.

Проверить можно просто открыв эту ссылку в браузере: должна ответить строкой
с количеством записей.

### Как оно договаривается

У каждой строки есть скрытый столбец `ID` и столбец `Изменено`. Когда ты правишь
ячейку руками, скрипт сам проставляет туда время. При обмене побеждает та версия,
которую правили позже. Никакого сервера нет, только эти два столбца.

Три правила, чтобы не удивляться:

1. **Удалять строку в таблице бесполезно** — она вернётся при следующем обмене:
   телефон про удаление не знает. Ставь `да` в столбце `Удалено`.
2. **Столбец `ID` не трогать** — он машинный и скрыт. Новую строку можно завести
   прямо в таблице, оставив `ID` пустым: скрипт выдаст его сам.
3. **Стороны указываются именем.** Написал в `Объектах` заказчика, которого ещё
   нет, — скрипт заведёт его сам.

Переключатель **Обмениваться самому** держит связь без кнопок: телефон ходит в
таблицу при открытии пузыря и после каждой правки. Кнопка
**Синхронизировать сейчас** — то же самое вручную.

### Без интернета

Кнопка **Выгрузить CSV и копию** отдаёт четыре CSV (открываются в Excel, кириллица
не ломается) и файл `quickdeck.json` — полная копия реестра.

## Подпись приложения

Пока ключа нет, APK подписывается отладочным. Работает, но при каждом обновлении
телефон может потребовать сначала удалить старую версию.

Чтобы это ушло, один раз:

```
keytool -genkey -v -keystore release.jks -keyalg RSA -keysize 2048 -validity 10000 -alias quickdeck
certutil -encode release.jks release.txt
```

Открыть `release.txt`, скопировать всё между строками BEGIN/END и на GitHub
в **Settings → Secrets and variables → Actions** завести четыре секрета:

| Имя | Значение |
|---|---|
| `KEYSTORE_BASE64` | скопированный текст |
| `KEYSTORE_PASSWORD` | пароль хранилища |
| `KEY_ALIAS` | `quickdeck` |
| `KEY_PASSWORD` | пароль ключа |

Файл `release.jks` держать у себя и не заливать в репозиторий — при потере
обновления поверх ставиться перестанут.

---

## Чего НЕ надо делать

- Не удалять папку `app` — это исходный код.
- Не заливать `release.jks` и `keystore.properties` в репозиторий.
- Не выключать разрешение «Поверх других приложений» — пузырь пропадёт молча.
- Не ставить debug- и release-версию одновременно: это два разных приложения
  с разными реестрами (у debug в конце имени пакета стоит `.debug`).

Папку `_removed/` можно удалить: там лежат файлы от старой версии с полоской
у края, в сборку они не попадают.

## Если сборка упала

На вкладке **Actions** открыть красный прогон, развернуть шаг **Build** —
текст ошибки в самом низу. Скопировать и прислать мне.

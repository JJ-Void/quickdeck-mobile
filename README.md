# QuickDeck Mobile

Реестр компании под большой палец: объекты, договоры, заказчики, исполнители.
Живёт пузырём поверх любого приложения: тапнул — список, потянул — колесо разделов.

Kotlin + Jetpack Compose, minSdk 26, без базы данных и без сервера.
Визуально — та же система, что у десктопного QuickDeck (`DESIGN-SYSTEM.md`):
Manrope внутри приложения, линейные иконки на сетке 24, радиусы 24/16/12/10,
шаг сетки 4, шесть статусов одним словарём на все сущности.

Сборка `.apk` — на GitHub Actions. Порядок действий: `ПАМЯТКА.md`.

## Жест

```
              тап ─────────────── список последнего раздела
               │
    пузырь ────┼── потянул ────── колесо разделов
               │                  ≤ 56 dp   отмена
               │                  56…192    откроется список
               │                  > 192 dp  появится плюс: новая запись
               │                  ход вверх-вниз — 64 dp на раздел
               │
       долгое нажатие ─────────── пузырь оторвался, тащи куда удобно
```

Колесо стоит на месте, а выбор едет по нему, и всё считается от точки, где палец
лёг на пузырь, — не от края экрана. Поэтому жест одинаково работает, где бы пузырь
ни висел, и не спорит с системным «назад».

## Два окна, и почему именно два

Это главное решение всей мобильной части.

Окно **пузыря** маленькое и за время жеста никогда не меняет размер. Android
отменяет поток касаний, когда окно пересоздают, — из-за этого в первой версии
палец срывался на первом же движении. Система отдаёт весь жест тому окну, где
случилось нажатие, поэтому маленькое неподвижное окно спокойно ведёт палец через
весь экран.

Окно **панели** добавляется один раз при запуске и по умолчанию вообще не
принимает касания: пока идёт ведение по колесу, это чистая картинка. Касания оно
берёт только когда открыт список или карточка.

Ни одно из двух окон не бывает фокусируемым. Фокусируемый оверлей перехватывает
весь экран и его нечем закрыть — ровно это и было «наложением, которое не убрать».
А раз фокуса нет, нет и клавиатуры: всё, где нужно печатать, уехало в обычную
Activity (`SheetActivity`), где клавиатура, прокрутка и «назад» работают сами.

Пузырь всегда лежит поверх панели, и тап по нему закрывает её. Плюс скрим, плюс
крестик, плюс действие в уведомлении — залипнуть физически нечему.

## Что где

```
core/Tokens.kt         токены дизайн-системы плюс тёмная палитра панели
core/Type.kt           Manrope, шесть размеров, табличные цифры
core/Icons.kt          path-строки на сетке 24, обводка 1.75
data/Model.kt          Party / Site / Contract, статусы, слияние по метке времени
data/Store.kt          реестр в одном JSON, единственное место, где ставится updatedAt
data/Format.kt         1 250 000 ₽, «30 сент.», «просрочен на 4 дня»
data/Sync.kt           двусторонний обмен с Google-таблицей
data/Export.kt         CSV для Excel и копия JSON
overlay/BubbleService  два окна, перетаскивание, вибро, запуск форм
overlay/OverlayState   общее состояние обоих окон
overlay/Bubble.kt      пузырь и весь жест целиком
overlay/Wheel.kt       геометрия жеста и отрисовка колеса
overlay/Panel.kt       список, карточка, смена статуса в один тап
ui/                    строки, карточки, формы, поля — светлая тема приложения
SheetActivity.kt       формы и поиск: всё, где нужна клавиатура
MainActivity.kt        разрешения, разделы, настройка таблицы
```

## Данные

Лежат в `filesDir/quickdeck.json` внутри приложения. Наружу два пути:

- **Google-таблица — связь в обе стороны.** У каждой записи есть идентификатор и
  метка времени. При обмене побеждает та версия, которую правили позже: правка в
  телефоне уезжает в таблицу, правка в таблице приезжает в телефон. Удаление —
  не вырезанная строка, а пометка, иначе запись воскресала бы при каждом обмене.
  Код скрипта и настройка — `SHEETS.md`.
- **CSV + копия JSON** через системное «Поделиться» — на случай, когда интернета нет.

## Открыть в Android Studio

Обёртки Gradle в репозитории нет (CI собирает своим Gradle). Studio предложит
сгенерировать её при первом открытии — согласиться. Либо однократно:

```
gradle wrapper --gradle-version 8.9
```

## Что не сделано намеренно

- Нет актов и этапов сдачи: сначала нужно, чтобы связка «объект — договор —
  статус» стала привычной в ежедневной работе.
- Нет учёта оплат: сумма договора есть, платежей нет.
- Нет синхронизации напрямую между телефонами — общая точка одна, таблица.

Папка `_removed/` — старые `EdgeService` и `OverlayRoot` от версии с полоской
у края. Лежат вне `src`, не собираются, удалить можно в любой момент.

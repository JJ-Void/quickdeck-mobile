# QuickDeck Mobile

Реестр компании под большой палец: заказчики, объекты, договоры, исполнители.
Открывается свайпом от края поверх любого приложения — колесом, как панель быстрого
доступа в играх.

Kotlin + Jetpack Compose, minSdk 26, без базы данных и без сервера.
Визуально — та же система, что у десктопного QuickDeck (`DESIGN-SYSTEM.md`):
Manrope внутри приложения, линейные иконки на сетке 24, радиусы 24/16/12/10,
шаг сетки 4, шесть статусов одним словарём на все сущности.

Сборка `.apk` — на GitHub Actions. Порядок действий: `ПАМЯТКА.md`.

## Жест

```
      палец от края
           │
 ≤ 40 dp   │  40…200 dp        > 200 dp + 160 мс
 отмена    │  выбор пункта     появляется плюс
 (назад)   │  (ход вверх-вниз, │  отпустил — форма ввода
           │   56 dp на пункт) │
```

Уровень 1 — четыре раздела. Отпустил на разделе — тем же колесом идут записи этого
раздела. Отпустил на записи — карточка. Карточки и формы ложатся друг на друга
стопкой: нижнее окно уменьшается на 2 %, фон уплотняется.

Выбранный пункт — белая карточка с кольцом акцента 1.5 и свечением, а не заливка.
Смена пункта — вибро 8 мс, появление плюса — 18 мс.

## Что где

```
core/Tokens.kt      токены раздела 12 дизайн-системы, единственный источник цвета
core/Type.kt        Manrope, шесть размеров, табличные цифры для сумм и дат
core/Icons.kt       набор иконок: path-строки на сетке 24, обводка 1.75
data/Model.kt       Party / Site / Contract + один словарь статусов
data/Store.kt       весь реестр в одном JSON-файле, StateFlow наружу
data/Format.kt      1 250 000 ₽, «30 сент.», «просрочен на 4 дня»
data/Export.kt      CSV для Excel и отправка в Google-таблицу
overlay/EdgeService окно поверх других приложений: полоска ⇄ полный экран
overlay/Wheel.kt    геометрия жеста и отрисовка колеса
overlay/OverlayRoot состояния, уровни, стопка окон
ui/                 карточки, строки списков, формы, поля
MainActivity.kt     разрешения, сторона полоски, разделы, выгрузка
```

## Данные

Хранятся в `filesDir/quickdeck.json` внутри приложения. Наружу два пути:

- **CSV + копия JSON** через системное «Поделиться»;
- **Google-таблица** как архив — приложение шлёт весь реестр в веб-приложение
  Apps Script, оно перезаписывает четыре листа. Код и настройка — `SHEETS.md`.

Ручные правки в таблице затираются следующей отправкой: таблица — архив,
телефон — рабочее место.

## Открыть в Android Studio

Обёртки Gradle в репозитории нет (CI собирает своим Gradle). Studio предложит
сгенерировать её при первом открытии — согласиться. Либо однократно:

```
gradle wrapper --gradle-version 8.9
```

## Что не сделано намеренно

- Нет тёмной темы в оверлее: колесо всегда лежит на затемнении, светлые карточки
  читаются в обоих режимах. Токены для тёмной темы в `Tokens.kt` уже есть.
- Нет поиска по реестру: на первой сотне записей колесо быстрее строки поиска.
  Появится, когда записей станет больше.
- Нет синхронизации между телефонами: обмен через выгрузку.
